==================================================
1. WHAT IS A TUPLE?
==================================================

A tuple is an ordered collection of elements in Python.

Tuples are:

1. Ordered
2. Immutable
3. Allow duplicate values
4. Can store different data types
5. Can contain nested tuples
6. Can be indexed
7. Can be sliced
8. Can be used as dictionary keys if all their elements are hashable

Tuples are generally written using parentheses ().

Example:

```python
numbers = (10, 20, 30, 40, 50)

print(numbers)
```

Output:

(10, 20, 30, 40, 50)

12. TUPLES ARE IMMUTABLE
==================================================

The most important property of a tuple is that it is immutable.

Immutable means we cannot directly change, add, or remove tuple elements after creation.

Example:

```python
numbers = (10, 20, 30)

numbers[0] = 100
```

This produces:

TypeError


Lists are mutable:

```python
numbers = [10, 20, 30]

numbers[0] = 100
```

But tuples are immutable:

```python
numbers = (10, 20, 30)

numbers[0] = 100
```

This will give an error.


==================================================
13. WHY ARE TUPLES IMMUTABLE?
==================================================

Tuples are useful when data should not be modified.

Example:

```python
student = ("Ashu", 20, "CSE")
```

If these values should remain fixed, a tuple can be used.

Benefits:

1. Data protection
2. Can be used as dictionary keys when hashable
3. Generally smaller/lighter than equivalent lists
4. Useful for fixed collections
5. Can communicate that data is not intended to change

44. TUPLE AS DICTIONARY KEY
==================================================

A tuple containing only hashable elements can be used as a dictionary key.

==================================================
45. HASHABLE TUPLE
==================================================

A tuple is hashable only when all of its elements are hashable.

This can be used as a dictionary key:

```python
a = (1, 2, 3)

data = {
    a: "Hello"
}
```

But this cannot:

```python
a = (1, [2, 3])

data = {
    a: "Hello"
}
```

because the tuple contains a list, and lists are unhashable.

52. TUPLE VS LIST
==================================================

Tuple:

```python
numbers = (10, 20, 30)
```

List:

```python
numbers = [10, 20, 30]
```

Main differences:

Tuple:
- Immutable
- Uses ()
- Fewer methods
- Good for fixed data
- Can be dictionary key if hashable
- Usually smaller than equivalent list

List:
- Mutable
- Uses []
- Many methods
- Good for changing data
- Cannot be dictionary key
- More flexible


==================================================

==================================================

Feature             Tuple              List

Syntax              ()                 []

Mutable              No                 Yes

Duplicate values     Yes                Yes

Indexing             Yes                Yes

Slicing              Yes                Yes

append()             No                 Yes

remove()             No                 Yes

==================================================
54. WHY USE TUPLE INSTEAD OF LIST?
==================================================

Use tuple when:

1. Data should not change.
2. You want to represent a fixed collection.
3. You want a potentially more compact immutable container.
4. You need a hashable composite key.
5. You want to communicate that the data is fixed.


Example:

```python
rgb = (255, 0, 0)
```

This represents a fixed RGB value.


==================================================
55. TUPLE MEMORY
==================================================

Tuples are generally more memory-efficient than lists for the same elements because tuples are immutable and have a simpler internal structure.

Example:

```python
a = [10, 20, 30]
b = (10, 20, 30)
```

Both store references to the same values conceptually, but the containers themselves have different overhead.

71. TUPLE COMPREHENSION
==================================================

Python does NOT have a separate tuple comprehension syntax.

For example:

```python
result = (x * x for x in range(5))
```

This creates a generator, not a tuple.

To create a tuple:

```python
result = tuple(x * x for x in range(5))

print(result)
```

Output:

(0, 1, 4, 9, 16)

```python
    if num not in result:
        result.append(num)

result = tuple(result)

print(result)
```

Output:

86. IMPORTANT INTERVIEW QUESTIONS

Q1. What is a tuple?

A tuple is an ordered and immutable collection in Python.


Q2. How do you create a tuple?

```python
a = (10, 20, 30)
```


Q3. Can a tuple contain duplicate values?

Yes.

```python
a = (10, 20, 10, 30)
```


Q4. Can a tuple contain different data types?

Yes.

```python
a = (10, "Ashu", 20.5, True)
```


Q5. Can we modify a tuple?

No. Tuples are immutable.


Q6. How many methods does a tuple have?

The tuple type has two main methods:

count()
index()


Q7. Difference between list and tuple?

List is mutable, while tuple is immutable.


Q8. Can a tuple be a dictionary key?

Yes, if all elements of the tuple are hashable.


Q9. Can a list be a dictionary key?

No, because lists are unhashable.


Q10. What is tuple packing?

Combining multiple values into a tuple.

```python
a = 10, 20, 30
```


Q11. What is tuple unpacking?

Assigning tuple elements to separate variables.

```python
a, b, c = (10, 20, 30)
```


Q12. How do you create a single-element tuple?

```python
a = (10,)
```


Q13. Does Python have tuple comprehension?

No. A parenthesized expression such as:

```python
(x for x in range(5))
```

creates a generator expression, not a tuple.


Q14. How can you convert a list into a tuple?

```python
a = tuple(my_list)
```


Q15. How can you convert a tuple into a list?

```python
a = list(my_tuple)
```
