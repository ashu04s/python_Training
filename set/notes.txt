==================================================
1. WHAT IS A SET?
==================================================

A set is an unordered collection of unique elements in Python.

Main properties of a set:

1. Unordered
2. Mutable
3. Does not allow duplicate elements
4. Elements must be hashable
5. Does not support indexing
6. Does not support slicing
7. Supports mathematical set operations
8. Can contain different hashable data types
9. A set itself is mutable and therefore unhashable

Example:

```python
numbers = {10, 20, 30, 40}

print(numbers)
```

Output may appear in an order such as:

```text
{40, 10, 20, 30}
```

The order should not be relied upon.


==================================================
2. CREATING A SET
==================================================

Basic set:

```python
numbers = {10, 20, 30, 40}
```

String set:

```python
names = {"Ashu", "Rahul", "Aman"}
```

Mixed set:

```python
data = {10, "Ashu", 20.5, True}
```

Empty set:

IMPORTANT:

```python
a = {}
```

This creates an empty dictionary, NOT a set.

Correct way to create an empty set:

```python
a = set()
```

Check:

```python
print(type(a))
```

Output:

```text
<class 'set'>
```


==================================================
3. DUPLICATE VALUES IN SET
==================================================

A set automatically removes duplicate values.

Example:

```python
numbers = {10, 20, 10, 30, 20, 40}

print(numbers)
```

Output contains only unique values:

```text
{10, 20, 30, 40}
```

Therefore:

```text
Set = Collection of unique elements
```


==================================================
4. SET IS UNORDERED
==================================================

A set does not provide sequence-style indexing.

Example:

```python
numbers = {10, 20, 30, 40}
```

You should not expect:

```python
numbers[0]
```

This gives:

```text
TypeError
```

Use a loop to access elements:

```python
for num in numbers:
    print(num)
```


==================================================
5. SET DOES NOT SUPPORT INDEXING
==================================================

Lists support:

```python
numbers = [10, 20, 30]

print(numbers[0])
```

Sets do not:

```python
numbers = {10, 20, 30}

print(numbers[0])
```

This gives an error because sets are not indexable.


==================================================
6. SET DOES NOT SUPPORT SLICING
==================================================

This is invalid:

```python
numbers = {10, 20, 30, 40}

print(numbers[1:3])
```

Sets do not support slicing.


==================================================
7. SET IS MUTABLE
==================================================

A set can be modified after creation.

Example:

```python
numbers = {10, 20, 30}

numbers.add(40)

print(numbers)
```

Output:

```text
{10, 20, 30, 40}
```


==================================================
8. ADD ELEMENT USING add()
==================================================

`add()` adds one element to a set.

Syntax:

```python

```

Example:

```python

numbers.add(40)

print(numbers)
```


==================================================
9. ADDING DUPLICATE USING add()
==================================================

If the element already exists, nothing new is added.

```python

print(numbers)
```

The set remains:

```text

```


==================================================
10. ADD MULTIPLE ELEMENTS USING update()
==================================================

`update()` adds multiple elements from an iterable.

Example:

```python

numbers.update([40, 50, 60])

print(numbers)
```

Result contains:

```text
{10, 20, 30, 40, 50, 60}
```


You can use a tuple:

```python

```

You can use another set:

```python
numbers.update({90, 100})
```


==================================================
11. DIFFERENCE BETWEEN add() AND update()
==================================================

`add()` adds one object as one element.

```python
a = {1, 2, 3}

a.add(4)
```

Result:

```text
{1, 2, 3, 4}
```

`update()` adds elements from an iterable.

```python
a = {1, 2, 3}

a.update([4, 5, 6])
```

Result:

```text
{1, 2, 3, 4, 5, 6}
```


Important example:

```python
a = {1, 2, 3}

a.add([4, 5])
```

This gives an error because a list is unhashable.

But:

```python
a.update([4, 5])
```

works.


==================================================
12. REMOVE ELEMENT USING remove()
==================================================

`remove()` removes a specific element.

```python
numbers = {10, 20, 30, 40}

numbers.remove(30)

print(numbers)
```


IMPORTANT:

If the element does not exist, `remove()` raises `KeyError`.

Example:

```python

```

This gives:

```text

```


==================================================
13. discard()
==================================================

`discard()` also removes an element.

Difference:

`remove()` -> gives error if element doesn't exist.

`discard()` -> does NOT give an error if element doesn't exist.

Example:

```python
numbers = {10, 20, 30}

numbers.discard(20)

print(numbers)
```

Example:

```python
numbers.discard(100)
```

No error.


==================================================
14. remove() VS discard()
==================================================

```text
remove()
---------
Element exists     -> removes it
Element absent     -> KeyError


discard()
---------
Element exists     -> removes it
Element absent     -> no error
```

28. UNION
==================================================

Union combines all unique elements from two sets.

Operator:

```python
|
```

Method:

```python
union()
```

Example:

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)
```

Output:

```text
{1, 2, 3, 4, 5}
```

Using method:

```python
print(a.union(b))
```


==================================================
29. INTERSECTION
==================================================

Operator:


Method:

```python

```

```python

b = {2, 3, 4}

print(a & b)
```

Output:

```text
{2, 3}
```

Using method:

```python
print(a.intersection(b))
```


==================================================
30. DIFFERENCE
==================================================

Difference gives elements present in the first set but not in the second.

Operator:

```python

```

```python
print(a - b)
```

Output:

```text

```

Important:

```python
a - b
```

is not necessarily the same as:


Example:

```python

```

Output:

```text

```

==================================================

A set A is a subset of B if every element of A is also present in B.

Operator:



Output:

```text

```

Using operator:

```python
print(a <= b)
```

63. FROZENSET
==================================================

A `frozenset` is an immutable version of a set.

Normal set:

```python
a = {1, 2, 3}
```

Frozen set:

```python
a = frozenset({1, 2, 3})
```

A frozenset cannot be modified.

It has no:

```text
add()
remove()
discard()
pop()
clear()
```

because it is immutable.


==================================================
64. FROZENSET EXAMPLE
==================================================

```python
a = frozenset([1, 2, 3])

print(a)
```

Trying:

```python
a.add(4)
```

gives an error.


==================================================
65. WHY USE FROZENSET?
==================================================

Use frozenset when:

1. You need an immutable set.
2. You want to use a set-like object as a dictionary key.
3. You want to store a set inside another set.


Example:

```python
key = frozenset({1, 2, 3})

data = {
    key: "value"
}

print(data[key])
```

79. SET TIME COMPLEXITY
==================================================

Sets are implemented using hash tables.

Average-case complexity:

Add:

O(1)

Remove:

O(1)

Discard:

O(1)

Membership:

O(1)

Lookup:

O(1)

Average-case union/intersection/difference depend on the sizes of the sets involved.

Important:

These are average-case complexities, not guaranteed worst-case bounds.

84. WHY SET MEMBERSHIP IS FAST
==================================================

Example:

```python
numbers = {10, 20, 30, 40, 50}

print(30 in numbers)
```

Sets use hashing internally, allowing average O(1) membership testing.

This is why sets are commonly used when we need to quickly check whether an item exists.


==================================================
85. SET AND ORDER
==================================================

Do not write programs that depend on the iteration order of a set.

Example:

```python
numbers = {10, 20, 30, 40}

for num in numbers:
    print(num)
```

The order is not something your program should rely on.


If you need ordered data, use a list or another appropriate sequence.

93. IMPORTANT SET INTERVIEW QUESTIONS
==================================================

Q1. What is a set?

A set is a mutable collection of unique elements in Python.

Q2. Does a set allow duplicate values?

No.

Q3. Does a set support indexing?

No.

Q4. Does a set support slicing?

No.

Q5. How do you create an empty set?

```python
set()
```

Q6. What is the difference between `{}` and `set()`?

`{}` creates an empty dictionary.

`set()` creates an empty set.

Q7. What is the difference between remove() and discard()?

`remove()` raises KeyError when the element is absent.

`discard()` does not raise an error.

Q8. What is the difference between add() and update()?

`add()` adds one element.

`update()` adds elements from an iterable.

Q9. Can a list be an element of a set?

No, because lists are unhashable.

Q10. Can a tuple be an element of a set?

Yes, if all elements inside the tuple are hashable.

Q11. Can a set be a dictionary key?

No.

Q12. What is frozenset?

An immutable and hashable version of a set.

Q13. What is union?

Combines all unique elements.

Q14. What is intersection?

Returns common elements.

Q15. What is difference?

Returns elements present in the first set but not the second.

Q16. What is symmetric difference?

Returns elements that belong to either set but not both.

Q17. What is a subset?

A set whose every element is contained in another set.

Q18. What is a superset?

A set that contains every element of another set.

Q19. What is a disjoint set?

Two sets with no common elements.

Q20. Why is set membership fast?

Because sets use hash-table-based lookup internally.
