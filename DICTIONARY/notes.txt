==================================================
1. WHAT IS A DICTIONARY?
==================================================

A dictionary is a collection of data stored in the form of:

KEY : VALUE

A dictionary is used to store data with a unique key.

Example:

```python
student = {
    "name": "Ashu",
    "age": 20,
    "branch": "CSE"
}

print(student)
```

Output:

```text
{'name': 'Ashu', 'age': 20, 'branch': 'CSE'}
```

Main properties of a dictionary:

1. Stores data as key-value pairs
2. Mutable
3. Keys must be unique
4. Keys must be hashable
5. Values can be of any data type
6. Supports insertion order preservation in modern Python
7. Does not support numeric indexing like lists
8. Can contain nested dictionaries
9. Can contain different data types


==================================================

```python
    key3: value3
```

==================================================
5. KEY-VALUE PAIR
==================================================

Example:

```python
student = {
    "name": "Ashu",
    "age": 20
}
```

Here:

```text
"name" → key
"Ashu" → value

"age" → key
20     → value
```


==================================================
6. KEYS MUST BE UNIQUE
==================================================

A dictionary cannot have duplicate keys.

Example:

```python
student = {
    "name": "Ashu",
    "age": 20,
    "name": "Rahul"
}

print(student)
```

Output:

```text
{'name': 'Rahul', 'age': 20}
```

The later value replaces the earlier value.

Therefore:

KEY → UNIQUE


==================================================
7. VALUES CAN BE DUPLICATE
==================================================

Values do not need to be unique.

Example:

```python
marks = {
    "Ashu": 80,
    "Rahul": 80,
    "Aman": 90
}

print(marks)
```

Here two students have the same marks.

19. popitem()
==================================================

`popitem()` removes and returns the last inserted key-value pair.

Example:

```python
student = {
    "name": "Ashu",
    "age": 20,
    "city": "Hisar"
}

result = student.popitem()

print(result)
print(student)
```

Output:

```text
('city', 'Hisar')
{'name': 'Ashu', 'age': 20}
```

Modern Python dictionaries preserve insertion order, so `popitem()` removes the last inserted pair.

32. DICTIONARY ALIASING
==================================================

Be careful:

```python
a = {
    "name": "Ashu"
}

b = a

b["age"] = 20

print(a)
```

Output:

```text
{'name': 'Ashu', 'age': 20}
```

Because `a` and `b` refer to the same dictionary.

Use:

```python
b = a.copy()
```

to create a separate shallow copy.

==================================================

Python supports dictionary comprehension.

Syntax:



==================================================

IMPORTANT:

Dictionary is ordered in modern Python, but it is still not accessed using numeric indexes like a list.

==================================================
60. SHALLOW COPY VS DEEP COPY
==================================================

`copy()` creates a shallow copy.

Example:

```python
data = {
    "name": "Ashu",
    "marks": [80, 90]
}

new_data = data.copy()
```

The outer dictionaries are separate, but nested mutable objects may still be shared.

For a deep independent copy:

```python
import copy

new_data = copy.deepcopy(data)
```

Deep copy recursively copies nested objects.


==================================================
61. SETDEFAULT()
==================================================

`setdefault()` returns the value for a key.

If the key does not exist, it creates the key with the specified default value.

Example:

```python
student = {
    "name": "Ashu"
}

result = student.setdefault("age", 20)

print(result)
print(student)
```

Output:

```text
20
{'name': 'Ashu', 'age': 20}
```


If the key already exists:

```python
student = {
    "age": 21
}

result = student.setdefault("age", 20)

print(result)
print(student)
```

Output:

```text
21
{'age': 21}
```

The existing value is not replaced.


==================================================
62. setdefault() USE CASE
==================================================

It can be useful for grouping.

Example:

```python
students = {}

students.setdefault("CSE", []).append("Ashu")
students.setdefault("CSE", []).append("Rahul")
students.setdefault("ECE", []).append("Aman")

print(students)
```

Output:

```text
{
    'CSE': ['Ashu', 'Rahul'],
    'ECE': ['Aman']
}
```

65. JSON AND DICTIONARY
==================================================

Python dictionaries are commonly used to represent JSON-like data.

Example:

```python
student = {
    "name": "Ashu",
    "age": 20,
    "skills": ["Python", "Java", "React"]
}
```

JSON uses a very similar structure.

However, Python dictionaries and JSON are not exactly the same thing.

JSON is a text/data interchange format.

Python `json` module can convert between them.

`json.dumps()` converts a Python object to a JSON string.

68. PRACTICAL PROGRAM - COUNT FREQUENCY
==================================================

Dictionary is very useful for counting frequency.

```python
numbers = [10, 20, 10, 30, 20, 10]

frequency = {}

for num in numbers:
    if num in frequency:
        frequency[num] += 1
    else:
        frequency[num] = 1

print(frequency)
```

Output:

```text
{10: 3, 20: 2, 30: 1}
```

Access by key:
O(1)

Insert:
O(1)

Update:

O(1)

87. IMPORTANT INTERVIEW QUESTIONS
==================================================

Q1. What is a dictionary?

A dictionary is a mutable collection of key-value pairs.

Q2. Are dictionary keys unique?

Yes.

Q3. Can dictionary values be duplicated?

Yes.

Q4. Can dictionary keys be duplicated?

No. A later value replaces the earlier one.

Q5. Can a list be a dictionary key?

No, because a list is unhashable.

Q6. Can a tuple be a dictionary key?

Yes, if all its elements are hashable.

Q7. How do you create an empty dictionary?

```python
{}
```

or:

```python
dict()
```

Q8. How do you access a dictionary value?

```python
data["key"]
```

or:

```python
data.get("key")
```

Q9. Difference between `[]` and `get()`?

`data["key"]` raises `KeyError` if the key does not exist.

`data.get("key")` returns `None` by default.

Q10. What does `keys()` return?

A dynamic view of dictionary keys.

Q11. What does `values()` return?

A dynamic view of dictionary values.

Q12. What does `items()` return?

A dynamic view of key-value pairs.

Q13. What is dictionary comprehension?

A concise way to create dictionaries.

Example:

```python
{x: x*x for x in range(5)}
```

Q14. Are dictionaries ordered?

Modern Python dictionaries preserve insertion order.

Q15. What is `setdefault()`?

It returns the value for a key and, if the key does not exist, inserts it with a default value.

Q16. What is `popitem()`?

It removes and returns the last inserted key-value pair.

Q17. What is the average time complexity of dictionary lookup?

O(1).

Q18. Can a dictionary contain another dictionary?

Yes.

Q19. Can a dictionary value be a list?

Yes.

Q20. Can a dictionary key be a set?

No.

Q21. Can a frozenset be a dictionary key?

Yes, because frozenset is hashable.
