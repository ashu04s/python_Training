==================================================
1. WHAT IS DICTIONARY COMPREHENSION?
==================================================

Dictionary comprehension is a short way to create a dictionary using a single line of code.

It is similar to list comprehension, but it creates a dictionary using:

KEY : VALUE


==================================================
2. BASIC SYNTAX
==================================================

Syntax:

{key: value for item in iterable}


Example:

numbers = [1, 2, 3, 4, 5]

square = {x: x * x for x in numbers}

print(square)

Output:

{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}


==================================================
3. NORMAL FOR LOOP VS DICTIONARY COMPREHENSION
==================================================

Normal loop:

square = {}

for x in range(1, 6):
    square[x] = x * x

print(square)


Dictionary comprehension:

square = {x: x * x for x in range(1, 6)}

print(square)


Both produce:

{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

==================================================
13. IF CONDITION
==================================================

Syntax:

{key: value for item in iterable if condition}


Example:

numbers = range(1, 11)

result = {
    x: x * x
    for x in numbers
    if x % 2 == 0
}

print(result)


==================================================
14. IF-ELSE IN DICTIONARY COMPREHENSION
==================================================

Syntax:

{key: value_if_true if condition else value_if_false for item in iterable}


Example:

numbers = range(1, 6)

result = {
    x: "Even" if x % 2 == 0 else "Odd"
    for x in numbers
}

print(result)

Output:

{
    1: 'Odd',
    2: 'Even',
    3: 'Odd',
    4: 'Even',
    5: 'Odd'
}

24. NESTED DICTIONARY COMPREHENSION
==================================================

Dictionary comprehension can create nested dictionaries.

Example:

result = {
    x: {
        y: x * y
        for y in range(1, 4)
    }
    for x in range(1, 4)
}

print(result)


Output:

{
    1: {1: 1, 2: 2, 3: 3},
    2: {1: 2, 2: 4, 3: 6},
    3: {1: 3, 2: 6, 3: 9}
}

41. DICTIONARY COMPREHENSION VS LIST COMPREHENSION
==================================================

LIST COMPREHENSION:

[x * x for x in range(5)]

Output:

[0, 1, 4, 9, 16]


DICTIONARY COMPREHENSION:

{x: x * x for x in range(5)}

Output:

{
    0: 0,
    1: 1,
    2: 4,
    3: 9,
    4: 16
}


Difference:

List -> [ ]

Dictionary -> {key: value}

==================================================
43. IMPORTANT SYNTAX
==================================================

Basic:

{key: value for item in iterable}


With condition:

{key: value for item in iterable if condition}


With if-else:

{
    key: value_if_true if condition else value_if_false
    for item in iterable
}


With dictionary:

{
    key: value
    for key, value in dictionary.items()
}


==================================================
44. COMMON MISTAKE
==================================================

Wrong:

[x for x in range(5)]

This creates a LIST.


Correct dictionary comprehension:

{x: x for x in range(5)}


Remember:

LIST:

[expression for item in iterable]


DICTIONARY:

{key: value for item in iterable}


==================================================
45. IMPORTANT RULE
==================================================

Dictionary comprehension must create:

KEY : VALUE


Example:

{x: x * 2 for x in range(5)}

Here:

Key = x

Value = x * 2

From dictionary:

Filter dictionary:

Swap:

{value: key for key, value in data.items()}


==================================================
47. IMPORTANT POINTS
==================================================

1. Dictionary comprehension creates a dictionary.
2. It uses { }.
3. It must have key:value.
4. It is shorter than a normal for loop.
5. It can contain conditions.
6. It can contain if-else.
7. It can use zip().
8. It can use enumerate().
9. It can create nested dictionaries.
10. It can work with lists, tuples, sets and dictionaries.
11. Duplicate keys are overwritten.
12. Very complex comprehensions should be avoided for readability.


==================================================
48. ONE-LINE DEFINITION
==================================================

Dictionary comprehension is a concise way to create a dictionary by generating key-value pairs from an iterable, optionally using conditions.
