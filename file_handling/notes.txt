PYTHON FILE HANDLING — COMPLETE NOTES
======================================

1. WHAT IS FILE HANDLING?
--------------------------

File handling means creating, opening, reading, writing, updating and deleting files using Python.

Normally, Python program ka data program close hone ke baad memory se remove ho jata hai.

File ka use karke hum data permanently store kar sakte hain.

Example:

Student data
Employee data
Login information
Logs
Reports
Configuration
CSV/Text data


2. WHY DO WE NEED FILE HANDLING?
--------------------------------

File handling ke main purposes:

1. Data ko permanently store karna
2. Existing data ko read karna
3. New data write karna
4. Existing data update karna
5. Files create karna
6. Files delete karna
7. Large amount of data ko manage karna

6. READ MODE — "r"
------------------

"r" ka matlab Read.

Is mode me hum file ke existing data ko read karte hain.

Example:

file = open("data.txt", "r")

data = file.read()

print(data)

file.close()


Important:

"r" mode me file exist karni chahiye.

Agar file exist nahi karti to FileNotFoundError aayega.


Example:

file = open("abc.txt", "r")


Agar abc.txt exist nahi karti:

FileNotFoundError


7. WRITE MODE — "w"
-------------------

"w" ka matlab Write.

Is mode me file me new data write kar sakte hain.

Example:

file = open("data.txt", "w")

file.write("Hello Python")

file.close()


IMPORTANT:

Agar file already exist karti hai, to "w" mode purana data DELETE karke new data likhta hai.

Example:

Existing file:

Hello
World


Code:

file = open("data.txt", "w")
file.write("Python")
file.close()


New file:

Python


Agar file exist nahi karti, "w" mode automatically new file create kar deta hai.


8. APPEND MODE — "a"
--------------------

"a" ka matlab Append.

Is mode ka use existing data ke END me new data add karne ke liye hota hai.

Example:

file = open("data.txt", "a")

file.write("\nNew Data")

file.close()


Existing:

Hello
Python


After append:

Hello
Python
New Data


IMPORTANT:

"a" mode existing data ko delete nahi karta.


9. CREATE MODE — "x"
--------------------

"x" mode new file create karne ke liye use hota hai.

Example:

file = open("newfile.txt", "x")

file.write("Hello")

file.close()


IMPORTANT:

Agar file already exist karti hai to FileExistsError aayega.


Example:

file = open("data.txt", "x")


If data.txt already exists:

FileExistsError


10. READ + WRITE MODE — "r+"
----------------------------

"r+" ka matlab:

Read + Write


Example:

file = open("data.txt", "r+")

data = file.read()

print(data)

file.write("\nNew Data")

file.close()


IMPORTANT:

"r+" me file already exist karni chahiye.

Agar file exist nahi karti:

FileNotFoundError


11. WRITE + READ MODE — "w+"
----------------------------

"w+" = Write + Read

Example:

file = open("data.txt", "w+")

file.write("Hello Python")

file.seek(0)

data = file.read()

print(data)

file.close()


IMPORTANT:

"w+" existing data ko delete karta hai.

Agar file exist nahi karti, new file create hoti hai.


12. APPEND + READ MODE — "a+"
-----------------------------

"a+" = Append + Read


Example:

file = open("data.txt", "a+")

file.write("\nNew Data")

file.seek(0)

data = file.read()

print(data)

file.close()


IMPORTANT:

"a+" existing data ko preserve karta hai aur end me new data add karta hai.

Read karne ke liye generally seek(0) use karna padta hai.


13. BINARY READ MODE — "rb"
---------------------------

"rb" = Read Binary

Binary files ke liye use hota hai.

Example:

file = open("image.jpg", "rb")

data = file.read()

print(data)

file.close()


14. BINARY WRITE MODE — "wb"
----------------------------

"wb" = Write Binary

Binary data write karne ke liye use hota hai.

Example:

file = open("image.jpg", "wb")

file.write(binary_data)

file.close()


15. BINARY APPEND MODE — "ab"
-----------------------------

"ab" = Append Binary

Binary file ke end me data add karne ke liye use hota hai.

Example:

file = open("data.bin", "ab")

file.write(binary_data)

file.close()


16. BINARY READ + WRITE — "rb+"
------------------------------

"rb+" = Binary Read + Write


Example:

file = open("data.bin", "rb+")

data = file.read()

print(data)

file.close()


File ko already exist karna chahiye.


17. BINARY WRITE + READ — "wb+"
------------------------------

"wb+" = Binary Write + Read

IMPORTANT:

Existing binary data overwrite ho jayega.


Example:

file = open("data.bin", "wb+")

file.write(b"Hello")

file.seek(0)

print(file.read())

file.close()


18. BINARY APPEND + READ — "ab+"
--------------------------------

"ab+" = Binary Append + Read


Example:

file = open("data.bin", "ab+")

file.write(b"Hello")

file.seek(0)

print(file.read())

file.close()


19. FILE MODES QUICK TABLE
--------------------------

Mode     Meaning                 File Exists?       Old Data
------------------------------------------------------------

r        Read                    Must exist          Safe
w        Write                   Create if absent    Deleted
a        Append                  Create if absent    Safe
x        Create                  Must not exist      -
r+       Read + Write            Must exist          Safe
w+       Write + Read            Create if absent    Deleted
a+       Append + Read           Create if absent    Safe

rb       Read Binary             Must exist          Safe
wb       Write Binary            Create if absent    Deleted
ab       Append Binary           Create if absent    Safe
rb+      Binary Read + Write     Must exist          Safe
wb+      Binary Write + Read     Create if absent    Deleted
ab+      Binary Append + Read    Create if absent    Safe


20. CLOSING A FILE
------------------

File ko use karne ke baad close() karna important hai.

Example:

file = open("data.txt", "r")

data = file.read()

print(data)

file.close()


Why close?

1. Resources release hote hain
2. File properly save hoti hai
3. File lock issues avoid hote hain
4. System resources free hote hain


21. WITH STATEMENT
------------------

Python me recommended way hai:

with open()


Example:

with open("data.txt", "r") as file:

    data = file.read()

    print(data)


Yahan manually:

file.close()

likhne ki zarurat nahi hai.


Python automatically file close kar deta hai.


22. WHY with open() IS BETTER?
------------------------------

Without with:

file = open("data.txt", "r")

data = file.read()

file.close()


With:

with open("data.txt", "r") as file:

    data = file.read()


Second method better hai because:

1. File automatically close hoti hai
2. Exception hone par bhi file close ho sakti hai
3. Code clean hota hai
4. Recommended Python practice hai

78. INTERVIEW QUESTIONS
-----------------------

Q1. What is file handling?

Answer:

File handling is the process of creating, reading, writing, updating and deleting files using a programming language.


Q2. Difference between "w" and "a"?

Answer:

"w" overwrites existing data.

"a" adds new data at the end without deleting existing data.


Q3. Difference between "r" and "r+"?

Answer:

"r" is only for reading.

"r+" is for both reading and writing.


Q4. Difference between "w" and "w+"?

Answer:

"w" = write only.

"w+" = write + read.

Both overwrite existing data.


Q5. Difference between "a" and "a+"?

Answer:

"a" = append only.

"a+" = append + read.


Q6. What happens if file does not exist in "r" mode?

Answer:

FileNotFoundError occurs.


Q7. What happens if file already exists in "x" mode?

Answer:

FileExistsError occurs.


Q8. Why use with open()?

Answer:

It automatically closes the file and makes file handling safer and cleaner.


Q9. What is tell()?

Answer:

tell() returns the current position of the file pointer.


Q10. What is seek()?

Answer:

seek() moves the file pointer to a specified position.


Q11. What is readline()?

Answer:

readline() reads one line from a file.


Q12. What is readlines()?

Answer:

readlines() reads all lines and returns them as a list.


Q13. What is writelines()?

Answer:

writelines() writes multiple strings to a file.


Q14. What is binary file?

Answer:

A binary file stores data in binary form and is commonly used for images, videos, audio and other non-text files.

83. GOLDEN RULES TO REMEMBER
----------------------------

1. r = Read
2. w = Write + overwrite
3. a = Append
4. x = Create
5. + = Read + Write
6. b = Binary
7. r requires existing file
8. x fails if file already exists
9. w creates file if it doesn't exist
10. a creates file if it doesn't exist
11. seek() changes pointer position
12. tell() tells pointer position
13. read() reads complete data
14. readline() reads one line
15. readlines() returns list of lines
16. write() writes one string
17. writelines() writes multiple strings
18. Prefer with open()
19. Use try-except for possible file errors
20. Use encoding="utf-8" for text files when appropriate
