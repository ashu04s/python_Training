| No. | Number Type            | Definition                                                                                                  | Example                              |
| --- | ---------------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| 1   | **Palindrome Number**  | Aisa number jo **reverse karne par bhi same** rahe.                                                         | `121 → 121`, `1331 → 1331`           |
| 2   | **Factorial**          | Kisi positive integer `n` ka factorial, `1 se n` tak sabhi numbers ka multiplication hota hai.              | `5! = 5×4×3×2×1 = 120`               |
| 3   | **Armstrong Number**   | Aisa number jisme **har digit ko total digits ki power** dene ke baad unka sum original number ke equal ho. | `153 = 1³+5³+3³ = 153`               |
| 4   | **Strong Number**      | Aisa number jisme **har digit ka factorial** nikal kar unka sum original number ke equal ho.                | `145 = 1!+4!+5! = 145`               |
| 5   | **Neon Number**        | Aisa number jisme number ka **square**, aur square ke digits ka sum original number ke equal ho.            | `9²=81 → 8+1=9`                      |
| 6   | **Automorphic Number** | Aisa number jiska **square usi number par end** hota hai.                                                   | `5²=25`, `25²=625`                   |
| 7   | **Happy Number**       | Aisa number jisme digits ke squares ka sum repeatedly karne par **1** milta hai.                            | `19 → 1²+9²=82 → 8²+2²=68 → ... → 1` |
| 8   | **Spy Number**         | Aisa number jisme **digits ka sum = digits ka product** ho.                                                 | `1124 → Sum=8, Product=8`            |
| 9   | **Prime Number**       | Aisa number jo **sirf 1 aur khud se divisible** ho.                                                         | `2, 3, 5, 7, 11`                     |
| 10  | **Perfect Number**     | Aisa number jiske **proper divisors ka sum = original number** ho.                                          | `6 → 1+2+3=6`                        |
| 11  | **Reverse Prime**      | Aisa prime number jiska **reverse bhi prime** ho.                                                           | `13 → 31`, dono prime                |
