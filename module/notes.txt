1. WHAT IS A MODULE?
==================================================

A module is a Python file containing Python code.

A module can contain:

1. Variables
2. Functions
3. Classes
4. Statements
5. Constants

A Python module normally has a .py extension.

Example:

math_utils.py

def add(a, b):
    return a + b


==================================================
2. WHY USE MODULES?
==================================================

Modules are used to:

1. Reuse code
2. Organize large programs
3. Avoid code repetition
4. Make code easier to maintain
5. Separate different parts of a project
6. Use Python's built-in functionality
7. Create reusable libraries


==================================================
3. TYPES OF MODULES
==================================================

Python modules can mainly be divided into:

1. Built-in / Standard Library Modules
2. User-Defined Modules
3. Third-Party Modules


==================================================
4. BUILT-IN / STANDARD LIBRARY MODULES
==================================================

Python provides many modules with its standard library.

Examples:

math
random
datetime
os
sys
json
re
statistics
time
calendar
collections
itertools
functools


Example:

import math

print(math.sqrt(25))

Output:

5.0


==================================================
5. USER-DEFINED MODULE
==================================================

A module created by the programmer is called a
user-defined module.

Suppose we create:

calculator.py

Code:

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b


Another file:

main.py

import calculator

print(calculator.add(10, 5))

print(calculator.subtract(10, 5))


==================================================
6. import STATEMENT
==================================================

The import statement is used to import a module.

Syntax:

import module_name


Example:

import math

print(math.sqrt(16))


==================================================
7. ACCESSING MODULE MEMBERS
==================================================

Use dot operator:

module_name.member_name


Example:

import math

print(math.pi)

print(math.sqrt(25))


Here:

math -> module

pi -> variable/constant

sqrt -> function


==================================================
8. IMPORT MULTIPLE MODULES
==================================================

You can import multiple modules.

Example:

import math
import random
import datetime


Or:

import math, random


Better style:

import math
import random


==================================================
9. IMPORT SPECIFIC FUNCTION
==================================================

Use:

from module import function


Example:

from math import sqrt

print(sqrt(25))

Output:

5.0


Now we don't need:

math.sqrt()


==================================================
10. IMPORT MULTIPLE MEMBERS
==================================================

Example:

from math import sqrt, pi

print(sqrt(25))
print(pi)


==================================================
11. from module import *
==================================================

You can import all names from a module.

Example:

from math import *

print(sqrt(25))
print(pi)


IMPORTANT:

Using * is generally discouraged in larger programs
because it can make it unclear where names came from
and can cause naming conflicts.


==================================================
12. IMPORT WITH ALIAS
==================================================

Use "as" to create an alias.

Example:

import math as m

print(m.sqrt(25))


Here:

math -> original module name

m -> alias


==================================================
13. ALIAS FOR FUNCTION
==================================================

Example:

from math import sqrt as s

print(s(25))


==================================================
14. __name__ IN MODULE
==================================================

Every Python module has a special variable:

__name__


When a file is run directly:

__name__ == "__main__"


When the file is imported:

__name__ == module_name


==================================================
15. if __name__ == "__main__"
==================================================

This is commonly used to prevent some code from
running automatically when the module is imported.

Example:

def add(a, b):
    return a + b


if __name__ == "__main__":
    print(add(10, 20))


If the file is run directly:

The print statement executes.


If imported:

The print statement does not execute.

==================================================

Python caches imported modules in:

Example:

When a module is imported, Python generally does not
execute its top-level code from scratch every time it is
imported in the same Python process.

A package is a way to organize related Python modules
into a directory structure.

Example:

project/
|
|-- main.py
|
|-- calculator/
    |
    |-- __init__.py
    |-- add.py
    |-- subtract.py

==================================================
42. MODULE VS PACKAGE
==================================================

MODULE:

Usually one .py file containing Python code.


PACKAGE:

A directory used to organize related modules.


Example:

calculator.py

-> Module


calculator/

    add.py
    subtract.py

-> Package


==================================================
43. __init__.py
==================================================

__init__.py is commonly used in Python packages.

Example:

calculator/
|
|-- __init__.py
|-- add.py
|-- subtract.py


It can contain package initialization code and can
control what is exposed by package-level imports.


Modern Python also supports namespace packages that do
not require __init__.py, but regular packages commonly
use it.


==================================================
44. IMPORT FROM PACKAGE
==================================================

Suppose:

calculator/
|
|-- __init__.py
|-- add.py


add.py:

def add(a, b):
    return a + b


main.py:

from calculator.add import add

print(add(10, 20))


==================================================
45. IMPORT MODULE FROM PACKAGE
==================================================

Example:

from calculator import add

If add is a module, you can use:

add.add(10, 20)


The exact behavior depends on the package structure
and what is exposed through __init__.py.

module1 and module2 are submodules of mypackage.

==================================================
55. MODULE NAME CONFLICT
==================================================

Suppose your file is named:

math.py


Then:

import math

may import your local math.py instead of the standard
library math module depending on the import search path.

Therefore, avoid naming your files after standard library
modules.


Examples to avoid:

math.py
random.py
json.py
os.py
sys.py


==================================================
56. CIRCULAR IMPORT
==================================================

A circular import occurs when modules depend on each other
directly or indirectly.

Example:

module_a imports module_b

module_b imports module_a


This can cause import errors or partially initialized
modules.

Better solution:

1. Rearrange code
2. Move shared code to another module
3. Use local imports only when appropriate


==================================================
57. MODULE DESIGN
==================================================

A good module should generally:

1. Have one clear purpose
2. Use meaningful names
3. Avoid unnecessary global state
4. Keep reusable functions/classes separate
5. Include documentation where useful
6. Avoid circular dependencies


==================================================
58. __all__
==================================================

__all__ can define names intended for wildcard imports.

Example:

__all__ = ["add", "subtract"]


Then:

from calculator import *


will expose the names listed in __all__.

IMPORTANT:

Explicit imports are generally clearer than wildcard imports.


==================================================
59. MODULE LEVEL CODE
==================================================

Code written directly in a module is executed when the
module is imported.

Example:

print("Module loaded")


If another file runs:

import mymodule


The message can be printed during import.


Use:

if __name__ == "__main__":

to separate script-only code from importable code.


==================================================
60. MODULE WITH MAIN FUNCTION
==================================================

Good structure:

def add(a, b):
    return a + b


def main():
    print(add(10, 20))


if __name__ == "__main__":
    main()


This allows the file to be:

1. Run directly
2. Imported safely


==================================================
61. MODULE EXECUTION FLOW
==================================================

When Python imports a module:

1. Python finds the module
2. Creates/initializes the module
3. Executes its top-level code
4. Stores the module in sys.modules
5. Makes the module available to the importer
