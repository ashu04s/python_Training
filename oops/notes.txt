====================================================================
                    1. WHAT IS OOP?
====================================================================

OOP = Object-Oriented Programming.

It is a programming paradigm where programs are organized
around objects and classes.

Main concepts:

    Class
    Object
    Attributes
    Methods

Four major pillars:

    1. Encapsulation
    2. Inheritance
    3. Polymorphism
    4. Abstraction


Real-world example:

Student

Attributes:

    name
    age
    course
    roll_number

Behaviors:

    study()
    attend_class()
    give_exam()

In Python:

    Student = Class
    Ashu = Object


====================================================================
                    2. PROCEDURAL VS OOP
====================================================================

Procedural Programming:

    Program is organized around functions and procedures.

OOP:

    Program is organized around objects.

Procedural example:

    calculate_salary()
    calculate_tax()
    print_employee()

OOP:

    Employee
        calculate_salary()
        calculate_tax()
        display()


Advantages of OOP:

    Code reuse
    Maintainability
    Scalability
    Modularity
    Encapsulation
    Easier testing


====================================================================
                    3. CLASS
====================================================================

A class is a blueprint/template for creating objects.

Example:

class Student:
    pass


Student is a class.


====================================================================
                    4. OBJECT
====================================================================

An object is an instance of a class.

Example:

class Student:
    pass


s1 = Student()
s2 = Student()


Here:

    Student = Class
    s1 = Object
    s2 = Object


====================================================================
                    5. ATTRIBUTES
====================================================================

Attributes are data associated with an object/class.

Example:

class Student:

    college = "MIET"

    def __init__(self, name):
        self.name = name


Here:

    college = Class Attribute
    name = Instance Attribute


====================================================================
                    6. METHODS
====================================================================

A method is a function defined inside a class.

Example:

class Student:

    def study(self):
        print("Student is studying")


study() is a method.


====================================================================
                    7. self
====================================================================

self refers to the current object.

Example:

class Student:

    def __init__(self, name):
        self.name = name


s = Student("Ashu")


self refers to s.

Approximately:

Student.__init__(s, "Ashu")


Important:

self is a convention, not a reserved keyword.

But always use self for normal instance methods.


====================================================================
                    8. __init__()
====================================================================

__init__() initializes an already-created object.

Example:

class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age


s = Student("Ashu", 20)


Important:

__init__() is technically an initializer.

The actual object creation method is __new__().


====================================================================
                    9. __new__()
====================================================================

__new__() creates the object.

Example:

class Student:

    def __new__(cls):
        print("Creating object")
        return super().__new__(cls)

    def __init__(self):
        print("Initializing object")


s = Student()


Order:

    __new__()
        ↓
    __init__()


====================================================================
              10. OBJECT CREATION FLOW
====================================================================

When:

s = Student()


Python approximately does:

    1. Find Student class
    2. Call Student.__new__()
    3. Create object
    4. Call Student.__init__()
    5. Return object


Flow:

    Student()
       |
       v
    __new__()
       |
       v
    Object created
       |
       v
    __init__()
       |
       v
    Object ready


====================================================================
              11. INSTANCE VARIABLES
====================================================================

Variables belonging to individual objects.

Example:

class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age


s1 = Student("Ashu", 20)
s2 = Student("Rahul", 21)


s1.name = Ashu
s2.name = Rahul


Each object has separate instance data.


====================================================================
              12. CLASS VARIABLES
====================================================================

Variables shared by the class/objects.

Example:

class Student:

    college = "MIET"

    def __init__(self, name):
        self.name = name


college is a class variable.


====================================================================
              13. LOCAL VARIABLES
====================================================================

Variables created inside a method without self.

Example:

class Student:

    def show(self):

        message = "Hello"

        print(message)


message is a local variable.

It belongs only to that method execution.


====================================================================
              14. INSTANCE METHODS
====================================================================

Instance methods work with object data.

Example:

class Student:

    def __init__(self, name):
        self.name = name

    def show(self):
        print(self.name)


s = Student("Ashu")

s.show()


First parameter:

    self


====================================================================
              15. CLASS METHODS
====================================================================

Class methods work with class-level data.

Use:

@classmethod


Example:

class Student:

    college = "MIET"

    @classmethod
    def show_college(cls):
        print(cls.college)


Student.show_college()


cls refers to the class.


====================================================================
              16. STATIC METHODS
====================================================================

Static methods do not automatically receive:

    self
    cls


Use:

@staticmethod


Example:

class Calculator:

    @staticmethod
    def add(a, b):
        return a + b


print(Calculator.add(10, 20))


Use static methods for utility operations related to a class.


====================================================================
        17. INSTANCE vs CLASS vs STATIC METHOD
====================================================================

Instance Method:

    No decorator
    First parameter = self
    Works with object data


Class Method:

    @classmethod
    First parameter = cls
    Works with class data


Static Method:

    @staticmethod
    No automatic self/cls


====================================================================
                    18. ENCAPSULATION
====================================================================

Encapsulation means:

    Bundling data and methods together
    and controlling access to data.


Example:

class BankAccount:

    def __init__(self, balance):
        self._balance = balance

    def deposit(self, amount):

        if amount > 0:
            self._balance += amount


Data and behavior are bundled inside the class.


====================================================================
                    19. PUBLIC MEMBERS
====================================================================

Public members have no underscore prefix.

Example:

class Student:

    def __init__(self):
        self.name = "Ashu"


s = Student()

print(s.name)

s.name = "Rahul"


Public members can be accessed from outside.


====================================================================
                    20. PROTECTED MEMBERS
====================================================================

Convention:

    _variable


Example:

class Student:

    _college = "MIET"


Protected members are intended for:

    class
    subclasses


BUT:

Python does NOT strictly prevent outside access.

This works:

s._college


So protected in Python is mainly a convention.


====================================================================
                    21. PRIVATE MEMBERS
====================================================================

Convention:

    __variable


Example:

class Student:

    def __init__(self):
        self.__name = "Ashu"


Direct:

s.__name


normally causes AttributeError.


====================================================================
                    22. NAME MANGLING
====================================================================

Python changes:

__name


approximately into:

_ClassName__name


Example:

class Student:

    def __init__(self):
        self.__name = "Ashu"


Technically:

s._Student__name


can access it.

Therefore Python private members are not absolutely
inaccessible.

They use name mangling.


Remember:

    name
        = public

    _name
        = protected convention

    __name
        = private-style/name mangling


====================================================================
                    23. GETTER
====================================================================

Getter reads private data.

Example:

class Student:

    def __init__(self):
        self.__age = 20

    def get_age(self):
        return self.__age


====================================================================
                    24. SETTER
====================================================================

Setter modifies private data.

Example:

class Student:

    def __init__(self):
        self.__age = 20

    def set_age(self, age):

        if age >= 0:
            self.__age = age


====================================================================
                    25. @property
====================================================================

@property provides getter-like syntax.

Example:

class Student:

    def __init__(self, age):
        self.__age = age

    @property
    def age(self):
        return self.__age

    @age.setter
    def age(self, value):

        if value >= 0:
            self.__age = value


s = Student(20)

print(s.age)

s.age = 21


====================================================================
                    26. INHERITANCE
====================================================================

Inheritance allows a child class to reuse parent class
functionality.

Example:

class Animal:

    def eat(self):
        print("Eating")


class Dog(Animal):

    def bark(self):
        print("Barking")


d = Dog()

d.eat()
d.bark()


Dog inherits Animal.


====================================================================
              27. TYPES OF INHERITANCE
====================================================================

Python supports:

    1. Single
    2. Multilevel
    3. Multiple
    4. Hierarchical
    5. Hybrid


====================================================================
              28. SINGLE INHERITANCE
====================================================================

One parent -> One child.

class Animal:
    pass

class Dog(Animal):
    pass


====================================================================
              29. MULTILEVEL INHERITANCE
====================================================================

Grandparent -> Parent -> Child.

class Animal:
    pass

class Dog(Animal):
    pass

class Puppy(Dog):
    pass


====================================================================
              30. MULTIPLE INHERITANCE
====================================================================

One child -> Multiple parents.

class Father:
    def drive(self):
        print("Driving")


class Mother:
    def cook(self):
        print("Cooking")


class Child(Father, Mother):
    pass


====================================================================
              31. HIERARCHICAL INHERITANCE
====================================================================

One parent -> Multiple children.

class Animal:
    pass

class Dog(Animal):
    pass

class Cat(Animal):
    pass


====================================================================
              32. HYBRID INHERITANCE
====================================================================

Combination of multiple inheritance types.

Example:

    Multiple + Multilevel
    Hierarchical + Multiple


====================================================================
              33. METHOD OVERRIDING
====================================================================

Child class provides its own implementation of a parent
method.

Example:

class Animal:

    def sound(self):
        print("Animal sound")


class Dog(Animal):

    def sound(self):
        print("Bark")


d = Dog()

d.sound()


Output:

Bark


====================================================================
                    34. super()
====================================================================

super() is used to access parent functionality.

Example:

class Animal:

    def show(self):
        print("Animal")


class Dog(Animal):

    def show(self):
        super().show()
        print("Dog")


d = Dog()

d.show()


Output:

Animal
Dog


super() is especially important in multiple inheritance because
it supports cooperative method calls.


====================================================================
                    35. MRO
====================================================================

MRO = Method Resolution Order.

It determines the order in which Python searches for methods.

Example:

class A:
    pass

class B(A):
    pass

class C(B):
    pass


print(C.mro())


Order:

C
B
A
object


====================================================================
              36. C3 LINEARIZATION
====================================================================

Python uses C3 Linearization to calculate MRO.

Important in multiple inheritance.

Example:

class A:
    pass

class B(A):
    pass

class C(A):
    pass

class D(B, C):
    pass


MRO approximately:

D
B
C
A
object


C3 ensures:

    Parent ordering is preserved.
    Local precedence is preserved.
    Consistent inheritance order is maintained.


====================================================================
              37. POLYMORPHISM
====================================================================

Polymorphism means:

    One interface, multiple forms.


Example:

class Dog:

    def sound(self):
        print("Bark")


class Cat:

    def sound(self):
        print("Meow")


def make_sound(animal):
    animal.sound()


make_sound(Dog())
make_sound(Cat())


Same:

    sound()

Different behavior.


====================================================================
              38. DUCK TYPING
====================================================================

Python focuses on behavior rather than exact type.

"if it walks like a duck and quacks like a duck,
treat it like a duck."


Example:

class Dog:

    def speak(self):
        print("Bark")


class Person:

    def speak(self):
        print("Hello")


def speak(obj):
    obj.speak()


speak(Dog())
speak(Person())


Python cares that speak() exists.


====================================================================
              39. METHOD OVERLOADING
====================================================================

Traditional method overloading like Java is not directly
supported.

Example:

class Calculator:

    def add(self, a):
        pass

    def add(self, a, b):
        pass


Second add() replaces the first one.


Python can simulate overloading using:

    Default arguments
    *args
    **kwargs


Example:

class Calculator:

    def add(self, a, b=0):
        return a + b


====================================================================
              40. OPERATOR OVERLOADING
====================================================================

Operator overloading means defining custom behavior for
operators.

Example:

a + b


Python calls approximately:

a.__add__(b)


Example:

class Number:

    def __init__(self, value):
        self.value = value

    def __add__(self, other):
        return Number(self.value + other.value)


a = Number(10)
b = Number(20)

c = a + b

print(c.value)


====================================================================
              41. ABSTRACTION
====================================================================

Abstraction means hiding unnecessary implementation details
and exposing essential functionality.

Example:

ATM:

    withdraw()
    deposit()
    check_balance()


User does not need to know internal implementation.


====================================================================
              42. ABSTRACT CLASS
====================================================================

Abstract class defines a common interface/behavior.

Python provides abstract classes using:

    abc


====================================================================
              43. ABSTRACT METHOD
====================================================================

An abstract method must be implemented by concrete child
classes.

Example:

from abc import ABC, abstractmethod


class Animal(ABC):

    @abstractmethod
    def sound(self):
        pass


class Dog(Animal):

    def sound(self):
        print("Bark")


====================================================================
              44. ABC
====================================================================

ABC = Abstract Base Class.

Import:

from abc import ABC, abstractmethod


ABC is used to create abstract classes.


====================================================================
              45. INTERFACE CONCEPT
====================================================================

Python does not have a separate:

interface

keyword like Java.

Interface-like designs can be created using:

    ABC
    abstractmethod
    Protocol


====================================================================
              46. PROTOCOL
====================================================================

Python's typing module provides Protocol.

Protocol supports structural typing.

Example:

from typing import Protocol


class Drawable(Protocol):

    def draw(self) -> None:
        ...


A class does not necessarily need to explicitly inherit
Drawable if it provides the required behavior.


====================================================================
              47. STRUCTURAL SUBTYPING
====================================================================

Structural subtyping means:

    An object is compatible because it has the required
    structure/behavior.

This is similar to duck typing but can be expressed formally
using typing.Protocol.


Nominal typing:

    Relationship based on explicit inheritance/type.


Structural typing:

    Relationship based on supported operations/methods.


====================================================================
              48. COMPOSITION
====================================================================

Composition = strong HAS-A relationship.

Example:

Car HAS-A Engine.


class Engine:

    def start(self):
        print("Engine starts")


class Car:

    def __init__(self):
        self.engine = Engine()


car = Car()


Engine is created as part of Car.


====================================================================
              49. AGGREGATION
====================================================================

Aggregation = weaker HAS-A relationship.

Contained object can exist independently.

Example:

Teacher can exist without Department.


class Teacher:
    pass


class Department:

    def __init__(self, teacher):
        self.teacher = teacher


teacher = Teacher()

department = Department(teacher)


====================================================================
              50. ASSOCIATION
====================================================================

Association means objects are related.

Example:

Teacher teaches Student.


class Teacher:
    pass

class Student:
    pass


teacher = Teacher()
student = Student()


No ownership is required.


====================================================================
              51. DEPENDENCY
====================================================================

A class temporarily uses another object.

Example:

class Printer:

    def print_document(self, document):
        print(document)


Printer depends on document.


====================================================================
              52. IS-A vs HAS-A
====================================================================

IS-A:

    Inheritance.

Dog IS-A Animal.


HAS-A:

    Composition/Aggregation.

Car HAS-A Engine.


====================================================================
              53. DEPENDENCY INJECTION
====================================================================

Instead of creating dependencies inside a class, provide them
from outside.

Example:

class Service:

    def __init__(self, repository):
        self.repository = repository


repository = Repository()

service = Service(repository)


Benefits:

    Low coupling
    Easier testing
    Flexibility


====================================================================
              54. COUPLING
====================================================================

Coupling = degree of dependency between components.

High coupling:

    Harder testing
    Harder maintenance
    Less flexibility


Low coupling:

    Easier testing
    Easier maintenance
    More flexibility


GOOD:

    Low coupling


====================================================================
              55. COHESION
====================================================================

Cohesion = how closely related responsibilities of a class are.

High cohesion:

    Focused class


Low cohesion:

    Unrelated responsibilities


GOOD:

    High cohesion
    Low coupling


====================================================================
              56. COMPOSITION OVER INHERITANCE
====================================================================

Prefer composition when inheritance does not represent a
strong IS-A relationship.

Inheritance:

    Dog IS-A Animal


Composition:

    Car HAS-A Engine


Composition can provide more flexibility.


====================================================================
              57. DUNDER METHODS
====================================================================

Dunder = Double Underscore.

Examples:

__init__
__new__
__str__
__repr__
__add__
__eq__
__len__
__call__


They define special behavior for Python objects.


====================================================================
              58. __str__()
====================================================================

Provides user-friendly string representation.

Example:

class Student:

    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"Student: {self.name}"


s = Student("Ashu")

print(s)


====================================================================
              59. __repr__()
====================================================================

Provides developer/debug representation.

Example:

class Student:

    def __repr__(self):
        return "Student()"


repr(student)


Ideally __repr__ should be unambiguous and useful for debugging.


====================================================================
              60. __len__()
====================================================================

Controls:

len(object)


Example:

class Team:

    def __init__(self, players):
        self.players = players

    def __len__(self):
        return len(self.players)


====================================================================
              61. __call__()
====================================================================

Makes an object callable like a function.

Example:

class Greeter:

    def __call__(self, name):
        print("Hello", name)


g = Greeter()

g("Ashu")


Internally:

g.__call__("Ashu")


====================================================================
              62. __getitem__()
====================================================================

Controls:

object[index]


Example:

class Numbers:

    def __init__(self):
        self.data = [10, 20, 30]

    def __getitem__(self, index):
        return self.data[index]


n = Numbers()

print(n[0])


====================================================================
              63. __setitem__()
====================================================================

Controls:

object[index] = value


Example:

class Numbers:

    def __init__(self):
        self.data = [10, 20, 30]

    def __setitem__(self, index, value):
        self.data[index] = value


====================================================================
              64. __delitem__()
====================================================================

Controls:

del object[index]


Example:

class Numbers:

    def __init__(self):
        self.data = [10, 20, 30]

    def __delitem__(self, index):
        del self.data[index]


====================================================================
              65. __contains__()
====================================================================

Controls:

item in object


Example:

class Team:

    def __init__(self):
        self.players = ["Ashu", "Rahul"]

    def __contains__(self, name):
        return name in self.players


====================================================================
              66. __iter__()
====================================================================

Makes an object iterable.

Example:

class Numbers:

    def __init__(self):
        self.data = [1, 2, 3]

    def __iter__(self):
        return iter(self.data)


====================================================================
              67. __next__()
====================================================================

Defines the next value of an iterator.

Example:

class Counter:

    def __init__(self, limit):
        self.current = 1
        self.limit = limit

    def __iter__(self):
        return self

    def __next__(self):

        if self.current <= self.limit:

            value = self.current
            self.current += 1

            return value

        raise StopIteration


====================================================================
              68. __enter__() and __exit__()
====================================================================

Used to create context managers.

Example:

class Demo:

    def __enter__(self):
        print("Entering")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Exiting")


with Demo():
    print("Inside")


====================================================================
              69. __getattr__()
====================================================================

Called when normal attribute lookup fails.

Example:

class Student:

    def __getattr__(self, name):
        return "Attribute not found"


s = Student()

print(s.age)


====================================================================
              70. __getattribute__()
====================================================================

Called for almost every normal attribute access.

Example:

class Demo:

    def __getattribute__(self, name):
        print("Accessing:", name)
        return object.__getattribute__(self, name)


Important:

Using __getattribute__ incorrectly can cause infinite recursion.

Use object.__getattribute__ when needed.


====================================================================
              71. __setattr__()
====================================================================

Controls attribute assignment.

Example:

class Student:

    def __setattr__(self, name, value):
        print("Setting:", name)
        object.__setattr__(self, name, value)


====================================================================
              72. __delattr__()
====================================================================

Controls attribute deletion.

Example:

class Student:

    def __delattr__(self, name):
        print("Deleting:", name)
        object.__delattr__(self, name)


====================================================================
              73. __eq__()
====================================================================

Controls ==.

Example:

class Student:

    def __init__(self, roll):
        self.roll = roll

    def __eq__(self, other):
        return self.roll == other.roll


====================================================================
              74. COMPARISON OPERATORS
====================================================================

Common dunder methods:

__eq__   -> ==
__ne__   -> !=
__lt__   -> <
__le__   -> <=
__gt__   -> >
__ge__   -> >=


====================================================================
              75. ARITHMETIC OPERATORS
====================================================================

__add__       +
__sub__       -
__mul__       *
__truediv__   /
__floordiv__  //
__mod__       %
__pow__       **


Other useful methods:

__neg__       -
__pos__       +
__abs__       abs()


====================================================================
              76. HASHING
====================================================================

Hashing converts an object/value into an integer hash.

Used by:

    dict
    set


Important methods:

__hash__()
__eq__()


Objects used as dictionary keys must satisfy appropriate
hash/equality requirements.


====================================================================
              77. __hash__()
====================================================================

Example:

class Student:

    def __hash__(self):
        return hash(self.roll)


Important:

If equality-relevant data changes after hashing, using a
mutable object as a dict key/set element can cause problems.


====================================================================
              78. OBJECT IDENTITY
====================================================================

Every object has identity.

Use:

id(object)


Identity asks:

    Is this exactly the same object?


====================================================================
              79. == vs is
====================================================================

==

Checks equality/value.


is

Checks identity.


Example:

a = [1, 2]
b = [1, 2]


a == b

True


a is b

False


Same values.

Different objects.


====================================================================
              80. MUTABLE vs IMMUTABLE
====================================================================

Mutable:

    list
    dict
    set
    most normal user-defined objects


Immutable:

    int
    float
    str
    tuple
    frozenset
    bool


Mutable object can change after creation.

Immutable object cannot be changed in place.


====================================================================
              81. SHALLOW COPY
====================================================================

Use:

copy.copy()


Shallow copy creates a new outer object.

Nested objects can still be shared.


Example:

import copy

a = [[1, 2], [3, 4]]

b = copy.copy(a)


====================================================================
              82. DEEP COPY
====================================================================

Use:

copy.deepcopy()


It recursively copies nested objects.

Example:

import copy

a = [[1, 2], [3, 4]]

b = copy.deepcopy(a)


====================================================================
              83. __copy__()
====================================================================

Can customize shallow copying.

Example concept:

def __copy__(self):
    ...


Python copy module can use this method.


====================================================================
              84. __deepcopy__()
====================================================================

Can customize deep copying.

Signature commonly:

def __deepcopy__(self, memo):
    ...


memo helps prevent repeated copying and handles recursive
object structures.


====================================================================
              85. GARBAGE COLLECTION
====================================================================

Python manages memory automatically.

Main concepts:

    Reference counting
    Cyclic garbage collector


When objects become unreachable, memory can eventually
be reclaimed.


====================================================================
              86. REFERENCE COUNTING
====================================================================

Python tracks references to objects.

Example concept:

a = Student()

b = a


Now both a and b refer to the same object.


When references disappear, the object's reference count can
decrease.


====================================================================
              87. weakref
====================================================================

weak references allow referencing an object without keeping
it alive solely because of that reference.

Module:

import weakref


Useful for:

    Caches
    Object tracking
    Avoiding strong reference cycles in certain designs


====================================================================
              88. DATACLASS
====================================================================

Dataclass is useful for data-focused classes.

Example:

from dataclasses import dataclass


@dataclass
class Student:

    name: str
    age: int


s = Student("Ashu", 20)


Dataclass can automatically generate methods such as:

    __init__
    __repr__
    __eq__


depending on configuration.


====================================================================
              89. ADVANCED DATACLASS
====================================================================

Important features:

    field()
    default
    default_factory
    frozen=True
    slots=True
    order=True
    kw_only=True


Example:

from dataclasses import dataclass, field


@dataclass
class Student:

    name: str
    subjects: list = field(default_factory=list)


default_factory prevents sharing one mutable default list
between instances.


====================================================================
              90. FROZEN DATACLASS
====================================================================

Example:

@dataclass(frozen=True)
class Student:

    name: str
    age: int


Instances become immutable-like.

Trying to modify fields raises an error.


====================================================================
              91. __slots__
====================================================================

__slots__ can restrict allowed instance attributes and can
reduce memory overhead in suitable cases.

Example:

class Student:

    __slots__ = ("name", "age")

    def __init__(self, name, age):
        self.name = name
        self.age = age


This prevents arbitrary attributes such as:

s.course = "CSE"

when course is not listed.


Note:

__slots__ has inheritance and weak-reference considerations.


====================================================================
              92. TYPE HINTS
====================================================================

Python supports type hints.

Example:

class Student:

    def __init__(self, name: str, age: int):
        self.name = name
        self.age = age

    def get_age(self) -> int:
        return self.age


Type hints help:

    IDEs
    Static analyzers
    Documentation
    Maintainability


Type hints are generally not enforced automatically at runtime.


====================================================================
              93. GENERIC CLASSES
====================================================================

Generics allow classes/functions to work with different types
while preserving type information.

Example:

from typing import Generic, TypeVar


T = TypeVar("T")


class Box(Generic[T]):

    def __init__(self, value: T):
        self.value = value


Box[int]
Box[str]


====================================================================
              94. TypeVar
====================================================================

TypeVar represents a generic type variable.

Example:

T = TypeVar("T")


It allows type relationships to be expressed.

Example:

def identity(value: T) -> T:
    return value


Input type and output type remain related.


====================================================================
              95. Generic
====================================================================

Generic is used to create generic classes.

Example:

from typing import Generic, TypeVar


T = TypeVar("T")


class Storage(Generic[T]):

s1 = Storage[int](10)

s2 = Storage[str]("Hello")

A descriptor can define:

Descriptors are the foundation of several Python features,

class Descriptor:

class Descriptor:

====================================================================
              99. __delete__()

class Descriptor:

    def __delete__(self, instance):
        ...


====================================================================
              100. DESCRIPTOR TYPES
====================================================================

Data Descriptor:

    Defines __set__ or __delete__
    and __get__ optionally.


Non-data Descriptor:

Important built-in descriptor examples:

    property
    methods
    classmethod

====================================================================
              101. __init_subclass__()
====================================================================

Called automatically when a class is subclassed.

Example:

class Parent:

Useful for:

    Validation
    Framework design
    Automatic subclass configuration

It is an advanced feature.

              103. METACLASSES

              105. CUSTOM METACLASS

class Meta(type):

    def __new__(mcls, name, bases, namespace):

        print("Creating:", name)

        return super().__new__(
            mcls,
            name,
            bases,
            namespace
        )


class Student(metaclass=Meta):

When Student class is created, Meta controls class creation.

Metaclasses are powerful and should be used carefully.


====================================================================
              107. CLASS CREATION PROCESS
====================================================================

Simplified process:

    class Student:
        ...


Python approximately:

    1. Determine metaclass
    2. Prepare class namespace
    3. Execute class body
    4. Create class object
    5. Call metaclass machinery
    6. Call __init_subclass__ where applicable
    7. Return class


This is advanced Python object model behavior.

====================================================================
              114. SINGLETON PATTERN
====================================================================

Singleton attempts to ensure one instance of a class.

Example:

    _instance = None

        if cls._instance is None:
            cls._instance = super().__new__(cls)

        return cls._instance

Output:

True


Use carefully.

            return Dog()

        elif animal_type == "cat":
            return Cat()

        raise ValueError("Unknown animal")

from abc import ABC, abstractmethod


class Account(ABC):

    bank_name = "ABC Bank"

    def __init__(
        self,
        account_number,
        owner,
        balance=0
    ):

        self.account_number = account_number
        self.owner = owner
        self._balance = balance

    @property
    def balance(self):
        return self._balance

    def deposit(self, amount):

        if amount <= 0:
            raise ValueError(
                "Amount must be positive"
            )

        self._balance += amount

    @abstractmethod
    def withdraw(self, amount):
        pass


class SavingsAccount(Account):

    def withdraw(self, amount):

        if amount > self._balance:
            raise ValueError(
                "Insufficient balance"
            )

        self._balance -= amount


account = SavingsAccount(
    "101",
    "Ashu",
    5000
)

account.deposit(1000)

account.withdraw(2000)

print(account.balance)
