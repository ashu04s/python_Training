1. WHAT IS LIST COMPREHENSION?
==================================================

List comprehension is a short and simple way to create a list using a single line of code.

Instead of writing multiple lines using a for loop, we can create a list in a compact way.

Advances:
1.require fewer lines of code
2. more time and space effecient

Normal approach:

numbers = []

for i in range(1, 6):
    numbers.append(i)

print(numbers)

Output:
[1, 2, 3, 4, 5]


Using list comprehension:

numbers = [i for i in range(1, 6)]

print(numbers)

Output:
[1, 2, 3, 4, 5]


==================================================
2. BASIC SYNTAX
==================================================

Syntax:

[expression for item in iterable]

Example:

numbers = [i for i in range(1, 6)]

Here:

i          -> item
range()    -> iterable
i          -> expression


Structure:

[ expression for item in iterable ]

18. IF-ELSE IN LIST COMPREHENSION
==================================================

Syntax:

[expression_if_true if condition else expression_if_false for item in iterable]

Example:

result = [
    "Even" if i % 2 == 0 else "Odd"
    for i in range(1, 6)
]

print(result)

Output:

['Odd', 'Even', 'Odd', 'Even', 'Odd']


==================================================
19. IF ONLY VS IF-ELSE
==================================================

IF ONLY:

[i for i in range(1, 11) if i % 2 == 0]

Here the if condition comes AFTER the for loop.


IF-ELSE:

["Even" if i % 2 == 0 else "Odd" for i in range(1, 11)]

Here if-else comes BEFORE the for loop.

28. NESTED LIST COMPREHENSION
==================================================

Nested list comprehension is used with nested loops.

Normal loop:

result = []

for i in range(1, 4):
    for j in range(1, 4):
        result.append((i, j))

print(result)


Using list comprehension:

result = [
    (i, j)
    for i in range(1, 4)
    for j in range(1, 4)
]

print(result)

Output:

[(1, 1), (1, 2), (1, 3),
 (2, 1), (2, 2), (2, 3),
 (3, 1), (3, 2), (3, 3)]


==================================================
29. NESTED LOOPS ORDER
==================================================

This:

result = [
    (i, j)
    for i in range(1, 4)
    for j in range(1, 4)
]

is equivalent to:

result = []

for i in range(1, 4):
    for j in range(1, 4):
        result.append((i, j))

Remember:

OUTER LOOP comes first.
INNER LOOP comes second.

53. LIST COMPREHENSION WITH SIDE EFFECTS
==================================================

Do NOT normally use list comprehension only for printing or modifying something.

Not recommended:

[print(x) for x in numbers]

Use a normal loop:

for x in numbers:
    print(x)

List comprehension should primarily be used to CREATE A LIST.


==================================================
54. LIST COMPREHENSION VS FOR LOOP
==================================================

FOR LOOP:

result = []

for x in range(1, 6):
    result.append(x * 2)


LIST COMPREHENSION:

result = [x * 2 for x in range(1, 6)]


List comprehension is useful when:

- Logic is simple
- We are creating a list
- We want to transform data
- We want to filter data


Normal for loop is better when:

- Logic is complicated
- Multiple statements are needed
- Code needs detailed debugging
- Side effects are involved


==================================================
55. LIST COMPREHENSION VS GENERATOR EXPRESSION
==================================================

List comprehension:

[x * x for x in range(5)]

Creates a list immediately.


Generator expression:

(x * x for x in range(5))

Creates a generator.

List comprehension:

- Uses []
- Creates complete list
- Uses more memory


Generator:

- Uses ()
- Produces values lazily
- Can save memory for large sequences

65. IMPORTANT INTERVIEW QUESTIONS
==================================================

Q1. What is list comprehension?

List comprehension is a concise way to create a list by applying an expression to each item of an iterable, optionally with a condition.


Q2. Basic syntax?

[expression for item in iterable]


Q3. Can list comprehension have an if condition?

Yes.

[x for x in numbers if x > 0]


Q4. Can list comprehension use if-else?

Yes.

["Even" if x % 2 == 0 else "Odd" for x in numbers]


Q5. Can list comprehension use nested loops?

Yes.

[(x, y) for x in range(3) for y in range(3)]


Q6. Can list comprehension work with strings?

Yes.

[x.upper() for x in "hello"]


Q7. Does list comprehension create a list?

Yes.


Q8. What is the difference between list comprehension and generator expression?

List comprehension creates a list immediately.

Generator expression produces values lazily.

67. MOST IMPORTANT RULES
==================================================

1. List comprehension is used to create a list.
2. It uses square brackets [].
3. Basic syntax:

[expression for item in iterable]

4. Filtering syntax:

[expression for item in iterable if condition]

5. If-else syntax:

[expression1 if condition else expression2 for item in iterable]

6. Nested loops are allowed.
7. Multiple conditions can be used.
8. List comprehension works with different iterables.
9. Avoid very complicated comprehensions.
10. Do not normally use list comprehension only for side effects.
11. List comprehension creates the complete list in memory.
12. Generator expressions are useful when lazy evaluation is needed.
