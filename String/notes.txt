==================================================
1. WHAT IS A STRING?
==================================================

A string is a sequence of characters enclosed inside quotes.
immutable

Python supports:

1. Single quotes -> ' '
2. Double quotes -> " "
3. Triple single quotes -> ''' '''
4. Triple double quotes -> """ """

Examples:

name = "Ashu"

city = 'Hisar'

message = """Hello Python"""

print(name)
print(city)
print(message)

Empty string:

print(name)

==================================================
4. STRING INDEXING
==================================================

Every character in a string has an index.

Example:

name = "Python"

Index:

P -> 0
y -> 1
t -> 2
h -> 3
o -> 4
n -> 5


Example:

name = "Python"

print(name[0])

Output:

P


print(name[3])

Output:

h


==================================================
5. NEGATIVE INDEXING
==================================================

Negative indexing starts from the end.

Example:

name = "Python"

P -> -6
y -> -5
t -> -4
h -> -3
o -> -2
n -> -1


Example:

print(name[-1])

Output:

n


print(name[-3])

Output:

h

16. STRING IMMUTABILITY
==================================================

Strings are IMMUTABLE.

This means we cannot directly change a character.

Wrong:

name = "Python"

name[0] = "J"

This gives:

TypeError


Correct:

name = "Python"

name = "J" + name[1:]

print(name)

Output:

Jython

18. upper()
==================================================

Converts all characters to uppercase.

19. lower()
==================================================

Converts all characters to lowercase.

==================================================
20. capitalize()
==================================================

Makes the first character uppercase and the remaining characters lowercase.

name = "pYTHON"

print(name.capitalize())

Output:

Python


==================================================
21. title()
==================================================

Makes the first character of each word uppercase.

text = "hello python world"

print(text.title())

Output:

==================================================
22. swapcase()
==================================================

Converts uppercase to lowercase and lowercase to uppercase.

text = "Hello PYTHON"

print(text.swapcase())

Output:

hELLO python


==================================================
23. casefold()
==================================================

Converts a string to a form suitable for case-insensitive comparison.

text = "HELLO"

print(text.casefold())

Output:

hello


casefold() is generally stronger than lower() for Unicode case-insensitive comparisons.

66. ESCAPE CHARACTERS
==================================================

Escape characters start with a backslash \.


\n -> New line

\t -> Tab

\\ -> Backslash

\' -> Single quote

\" -> Double quote

\b -> Backspace

\r -> Carriage return


Example:

print("Hello\nWorld")

Output:

Hello
World


Example:

print("Hello\tWorld")

Output:

Hello    World

94. MOST IMPORTANT INTERVIEW QUESTIONS
==================================================

Q1. What is a string?

A string is an immutable sequence of characters.


Q2. Are strings mutable?

No. Strings are immutable.


Q3. How do you reverse a string?

text[::-1]


Q4. Difference between find() and index()?

find() returns -1 if the substring is not found.

index() raises ValueError if it is not found.


Q5. Difference between split() and join()?

split() -> String to list

join() -> Iterable of strings to string


Q6. How do you convert a string to uppercase?

text.upper()


Q7. How do you remove spaces from both ends?

text.strip()


Q8. How do you check whether a string contains a word?

"word" in text


Q9. How do you check whether a string starts with something?

text.startswith("Hello")


Q10. How do you check whether a string contains only numbers?

text.isdigit()
