1. WHAT IS A FUNCTION?
==================================================

A function is a reusable block of code that performs a specific task.

Instead of writing the same code again and again, we create a function once and call it whenever needed.

we use snake case

Example:

def greet():
    print("Hello")

greet()

Output:

Hello


==================================================
2. WHY USE FUNCTIONS?
==================================================

Functions help to:

1. Reuse code
2. Reduce code repetition
3. Make code organized
4. Make code easier to understand
5. Make debugging easier
6. Divide a large program into smaller parts
7. Improve maintainability


==================================================
3. BASIC SYNTAX
==================================================

def function_name():
    # function body


Example:

def hello():
    print("Hello Python")


To call:

hello()


==================================================
4. FUNCTION CALL
==================================================

Creating a function:

def greet():
    print("Hello")


Calling a function:

greet()


IMPORTANT:

Defining a function does not execute it.

The function executes when it is called.


==================================================
5. FUNCTION WITH PARAMETERS(function definition)
==================================================

Parameters are variables written inside the function definition.

Example:

def greet(name):
    print("Hello", name)

greet("Ashu")

Output:

Hello Ashu


Here:

name = parameter
"Ashu" = argument


==================================================
6. PARAMETER VS ARGUMENT
==================================================

PARAMETER:

Variable defined in the function.

def greet(name):
    print(name)


ARGUMENT:

Actual value passed to the function.

greet("Ashu")


So:

name -> parameter
"Ashu" -> argument

7. MULTIPLE PARAMETERS

==================================================
8. RETURN STATEMENT
==================================================

return sends a value back from the function.

Example:

def add(a, b):
    return a + b

result = add(10, 20)

print(result)

Output:

30


==================================================
9. print() VS return
==================================================

print():

Displays the result.

def add(a, b):
    print(a + b)


return:

Sends the result back to the caller.

def add(a, b):
    return a + b


Example:

def add(a, b):
    return a + b

result = add(10, 20)

print(result)


IMPORTANT:

return is generally used when the result needs to be stored,
used in another calculation, or passed elsewhere.

10. FUNCTION WITHOUT RETURN
==================================================

15. POSITIONAL ARGUMENTS
==================================================

Arguments are matched according to their position.

Example:

def student(name, age):
    print(name, age)

student("Ashu", 20)

name = Ashu

==================================================
16. KEYWORD ARGUMENTS
==================================================

Arguments can be passed using parameter names.

Example:

def student(name, age):
    print(name, age)

student(age=20, name="Ashu")

Output:

Ashu 20


Order does not matter when using keyword arguments.


==================================================
17. POSITIONAL + KEYWORD ARGUMENTS
==================================================

Example:

def student(name, age, city):
    print(name, age, city)

student("Ashu", age=20, city="Hisar")


IMPORTANT:

Positional arguments must generally come before
keyword arguments.


Correct:

student("Ashu", age=20)


Wrong:

student(name="Ashu", 20)


==================================================
18. *args
==================================================

*args allows a function to accept any number of
positional arguments.

Example:

def add(*args):
    print(args)

add(10, 20, 30)

Output:

(10, 20, 30)


args is a tuple.


==================================================
19. *args EXAMPLE
==================================================

def add(*args):
    total = 0

    for i in args:
        total += i

    return total

print(add(10, 20, 30))

Output:

60


==================================================
20. **kwargs
==================================================

**kwargs allows a function to accept any number of
keyword arguments.

Example:

def student(**kwargs):
    print(kwargs)

student(name="Ashu", age=20, city="Hisar")

Output:

{
    'name': 'Ashu',
    'age': 20,
    'city': 'Hisar'
}


kwargs is a dictionary.


==================================================
21. *args VS **kwargs
==================================================

*args:

Accepts multiple positional arguments.

Example:

function(10, 20, 30)


**kwargs:

Accepts multiple keyword arguments.

Example:

function(name="Ashu", age=20)


*args -> tuple

**kwargs -> dictionary


==================================================
22. *args AND **kwargs TOGETHER
==================================================

def student(*args, **kwargs):

    print(args)
    print(kwargs)

    "Ashu",

    city="Hisar",
    marks=90

('Ashu', 20)

{'city': 'Hisar', 'marks': 90}


==================================================
23. UNPACKING WITH *
==================================================

24. UNPACKING WITH **

==================================================
25. LOCAL VARIABLE
==================================================

A variable created inside a function is usually local
to that function.

Example:

def test():
    x = 10
    print(x)

test()


Trying to use x outside the function:

print(x)

will cause NameError.


==================================================
26. GLOBAL VARIABLE
==================================================

A variable created outside a function is global.

Example:

x = 10

def test():
    print(x)

test()

Output:

10


==================================================
27. GLOBAL KEYWORD
==================================================

global allows a function to modify a global variable.

Example:

x = 10

def change():
    global x
    x = 20

change()

print(x)

Output:

20


Use global carefully.


==================================================
28. LOCAL VS GLOBAL
==================================================

Global:

x = 10

def test():
    x = 20
    print(x)

test()

print(x)


Output:

20
10


The x inside the function is local and does not change
the global x.


==================================================
29. NONLOCAL KEYWORD
==================================================

nonlocal is used in nested functions to modify a variable
from the nearest enclosing function scope.

Example:

def outer():

    x = 10

    def inner():

        nonlocal x
        x = 20

    inner()

    print(x)

outer()

Output:

20


==================================================
30. SCOPE
==================================================

Python follows the LEGB rule.

L = Local
E = Enclosing
G = Global
B = Built-in


Python searches for a variable in this order:

Local
↓
Enclosing
↓
Global
↓
Built-in

==================================================
38. map()
==================================================

map() applies a function to every item of an iterable.

Syntax:

map(function, iterable)


Example:

numbers = [1, 2, 3, 4]

result = map(lambda x: x * 2, numbers)

print(list(result))

Output:

[2, 4, 6, 8]


==================================================
39. filter()
==================================================

filter() selects items according to a condition.

Example:

numbers = [1, 2, 3, 4, 5, 6]

result = filter(
    lambda x: x % 2 == 0,
    numbers
)

print(list(result))

Output:

[2, 4, 6]


==================================================
40. reduce()
==================================================

reduce() repeatedly applies a function to the items
to produce a single result.

Need:

from functools import reduce


Example:

from functools import reduce

numbers = [1, 2, 3, 4]

result = reduce(
    lambda a, b: a + b,
    numbers
)

print(result)

Output:

10


==================================================
41. map() VS filter() VS reduce()
==================================================

map():

Transforms each item.

[1,2,3] -> [2,4,6]


filter():

Selects items.

[1,2,3,4] -> [2,4]


reduce():

Combines items into one result.

[1,2,3,4] -> 10


==================================================
42. RECURSION
==================================================

A function calling itself is called recursion.

Example:

def count(n):

    if n == 0:
        return

    print(n)

    count(n - 1)

count(5)

Output:

5
4
3
2
1


==================================================
43. BASE CASE IN RECURSION
==================================================

A recursive function must normally have a base case.

Example:

def factorial(n):

    if n == 0:
        return 1

    return n * factorial(n - 1)


Without a proper stopping condition,
recursion can continue until Python raises a recursion error.


==================================================
44. FACTORIAL USING RECURSION
==================================================

def factorial(n):

    if n == 0:
        return 1

    return n * factorial(n - 1)

print(factorial(5))

Output:

120


==================================================
45. FIBONACCI USING RECURSION
==================================================

def fibonacci(n):

    if n <= 1:
        return n

    return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(6))

Output:

8

62. HIGHER-ORDER FUNCTION
==================================================

A higher-order function is a function that:

1. Accepts another function as an argument
OR
2. Returns another function


Example:

def apply(func, value):
    return func(value)

square = lambda x: x * x

Output:

25


==================================================
63. CLOSURE
==================================================

A closure occurs when an inner function remembers and
uses variables from its enclosing function even after
the outer function has finished.

Example:

def multiplier(n):

    def multiply(x):
        return x * n

    return multiply


double = multiplier(2)

print(double(5))

Output:

10


Here inner function remembers n = 2.


==================================================
64. DECORATOR
==================================================

A decorator is a function that modifies or extends
the behavior of another function without changing
its original code.

Basic example:

def decorator(func):

    def wrapper():
        print("Before")
        func()
        print("After")

    return wrapper


@decorator
def greet():
    print("Hello")


greet()


Output:

Before
Hello
After


==================================================
65. DECORATOR WITH ARGUMENTS
==================================================

def decorator(func):

    def wrapper(*args, **kwargs):

        print("Before")

        result = func(*args, **kwargs)

        print("After")

        return result

    return wrapper


@decorator
def add(a, b):

    return a + b


print(add(10, 20))


==================================================
66. MULTIPLE DECORATORS
==================================================

Multiple decorators can be applied.

Example:

@decorator1
@decorator2
def greet():
    pass


The decorators are applied from the bottom upward.


==================================================
67. functools.wraps
==================================================

When writing decorators, functools.wraps helps preserve
the original function's metadata.

Example:

from functools import wraps

def decorator(func):

    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)

    return wrapper

69. yield VS return
==================================================

return:

- Ends the function
- Returns a result
- Function execution finishes


yield:

- Produces a value
- Pauses the function
- Can continue later
- Used for generators
