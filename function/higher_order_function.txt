# HIGHER-ORDER FUNCTION IN PYTHON

==================================================
1. WHAT IS A HIGHER-ORDER FUNCTION?
==================================================

A Higher-Order Function (HOF) is a function that does
at least ONE of these:

1. Takes another function as an argument
OR
2. Returns another function


==================================================
2. FUNCTION AS ARGUMENT
==================================================

Example:

def square(x):
    return x * x


def calculate(func, value):
    return func(value)


result = calculate(square, 5)

print(result)

Output:

25


Here:

square -> passed as an argument

calculate -> Higher-Order Function


==================================================
3. FUNCTION RETURNING ANOTHER FUNCTION
==================================================

Example:

def outer():

    def inner():
        print("Hello")

    return inner


result = outer()

result()

Output:

Hello


Here:

outer() returns inner function.

So outer() is a Higher-Order Function.


==================================================
4. HIGHER-ORDER FUNCTION WITH LAMBDA
==================================================

def calculate(func, value):
    return func(value)


result = calculate(
    lambda x: x * 2,
    5
)

print(result)

Output:

10


==================================================
5. map() AS HIGHER-ORDER FUNCTION
==================================================

map() takes a function as an argument.

Example:

numbers = [1, 2, 3, 4]

result = map(
    lambda x: x * 2,
    numbers
)

print(list(result))

Output:

[2, 4, 6]


==================================================
6. filter() AS HIGHER-ORDER FUNCTION
==================================================

filter() takes a function as an argument.

Example:

numbers = [1, 2, 3, 4, 5, 6]

result = filter(
    lambda x: x % 2 == 0,
    numbers
)

print(list(result))

Output:

[2, 4, 6]


==================================================
7. sorted() WITH FUNCTION
==================================================

sorted() can receive a function through key.

Example:

names = ["Ashu", "Rahul", "Aman"]

result = sorted(
    names,
    key=len
)

print(result)

Here:

len -> function passed as an argument

==================================================
8. CUSTOM HIGHER-ORDER FUNCTION
==================================================

def apply_operation(func, a, b):

    return func(a, b)


def add(a, b):
    return a + b


def multiply(a, b):
    return a * b


print(apply_operation(add, 10, 5))

print(apply_operation(multiply, 10, 5))


Output:

15
50


==================================================
9. HIGHER-ORDER FUNCTION + CLOSURE
==================================================

def multiplier(n):

    def multiply(x):
        return x * n

    return multiply


double = multiplier(2)

print(double(5))

Output:

10


Here:

multiplier() returns a function.

==================================================
10. HIGHER-ORDER FUNCTION + DECORATOR
==================================================

def decorator(func):

    def wrapper():

        print("Before")

        func()

        print("After")

    return wrapper


@decorator
def greet():

    print("Hello")


greet()


Output:

Before
Hello
After


Decorators are based on higher-order functions.


==================================================
11. FIRST-CLASS FUNCTION VS HIGHER-ORDER FUNCTION
==================================================

FIRST-CLASS FUNCTION:

Means functions can be treated like values.

Example:

x = greet


HIGHER-ORDER FUNCTION:

A function that accepts or returns another function.

Example:

def execute(func):
    func()


Simple difference:

First-class -> Property of functions

Higher-order -> Function that works with functions


==================================================
12. QUICK REVISION
==================================================

Higher-Order Function:

Function that:

1. Takes another function as argument
OR
2. Returns another function


Examples:

map()
filter()
sorted(key=...)
Custom functions
Decorators


Basic example:

def apply(func, value):
    return func(value)


def square(x):
    return x * x


print(apply(square, 5))

Output:

25

ONE-LINE DEFINITION
==================================================

A Higher-Order Function is a function that accepts
another function as an argument or returns another
function.
